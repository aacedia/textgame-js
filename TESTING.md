# Проверка проекта

Для запуска автоматических тестов требуется Node.js 18 или новее.

```bash
npm test
```

Тесты используют встроенный `node:test` и не требуют установки зависимостей.
Они проверяют базовые инварианты расчёта потребностей и эффектов, порядок
восстановления/уменьшения параметров в действиях, а также чтение и запись
локального сохранения, а также проверку структуры диалогов: существование
стартовых узлов, переходов `next`, ссылок из действий и корректность массива
вариантов ответа.

При старте игры `DataValidation` дополнительно проверяет весь загруженный
контент. Ошибки выводятся в консоль с путём до проблемного поля.

Эти тесты не заменяют проверку полного игрового сценария в браузере: DOM,
диалоги, загрузка/экспорт файлов и все игровые ветки должны дополнительно
проверяться в самой игре.
