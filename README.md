# textgame-js

Текстовая игра на HTML5 + JavaScript в духе QSP-плееров.

Можно запустить в браузере: [Live Demo](https://aacedia.github.io/textgame-js/)

## Что это

Игрок ходит по городу (квартира, спальный район, центр, Глитч-стрит, университет,
парк и т.д.), выбирает действия, тратит время и деньги, собирает предметы,
общается с NPC и получает стипендию. Есть день/время, инвентарь, потребности,
настроение, отношения с персонажами и сохранения в localStorage.

## Запуск

Открыть `index.html` в браузере. Сборки нет.

## Как устроено

Слои, снизу вверх:

    data → rules → save → game → ui

- **data** — только контент: локации, предметы, персонаж, NPC, диалоги,
  стартовое состояние. `window.GAME_DATA`.
- **rules** — чистые функции: условия, эффекты, время, расписания. `window.Rules`.
- **save** — обёртка над localStorage. `window.Save`.
- **game** — состояние, view-модель, диспетчеры. `window.Game`.
- **ui** — рендер и DOM. `window.UI`.

Модули регистрируют методы через `Object.assign(window.X, {...})`, поэтому
порядок подключения в `index.html` важен:

    data → rules → save → ui-* (ядро → соседи → ui.js) → game-* (state → viewmodel → actions → commands → game.js)

UI не читает `state` и не знает про правила. Логика не трогает DOM.
Встречаются они только в `game-viewmodel.js`.

## Что важно знать

Три независимых потока:
- `state` — локация, инвентарь, флаги, переменные, настройки интерфейса.
- `logEntries` — «История событий»: только переходы. Лимит 10, новые сверху.
- `infoEntries` — «Информация»: результат последнего действия. Лимит 6,
  заменяется целиком.

`Rules.applyEffect` — чистый редьюсер: принимает `state`, возвращает новый
`state` и массив сообщений `{ kind, text }`:
- `kind: "info"` — только в «Историю событий»;
- `kind: "infoExtra"` — и в «Историю», и в «Информацию» (деньги, чаевые, премия);
- `kind: "move"` — переход.

У действия может быть `variants` — случайные исходы. `Rules.pickVariant`
фильтрует их по `condition` и выбирает случайный. По умолчанию один и тот же
вариант не выпадает дважды подряд; чтобы разрешить повтор — `repeatable: true`.

`hiddenWhen` на действии скрывает его из списка (в отличие от `condition`,
который делает кнопку серой, но оставляет).

## Что где лежит

- **Контент** — `js/data/`. Локации по файлам в `js/data/locations/`,
  диалоги в `js/data/dialogues/`, предметы в `items.js`, NPC в `character.js`,
  стартовое состояние и константы в `data.js`.
- **Новое правило** (условие или эффект) — `js/rules/`.
- **Новый элемент UI** — отдельный `ui-*.js`, регистрация в `window.UI`,
  подключение до `ui.js`.
- **Новая игровая логика** — отдельный `game-*.js`, регистрация в `window.Game`,
  подключение до `game.js`.

Валидация данных запускается при старте (`js/data/data-validation.js`) и пишет
предупреждения в консоль.
