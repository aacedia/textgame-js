# textgame-js
Текстовая игра на HTML5 + JavaScript в духе QSP-плееров. Прототип.
[Live Demo](https://aacedia.github.io/textgame-js/)

## Что это

Игрок перемещается между локациями (Квартира, Улица, Университет, Магазин),
выбирает действия, собирает предметы, тратит время и деньги. Есть день/время,
инвентарь, расписания заведений, сохранение в localStorage.

## Запуск

Открыть `index.html` в браузере.

## Архитектура

Слои, снизу вверх:

    data → rules → game → ui

- **data** — только контент. `window.GAME_DATA`.
- **rules** — чистые функции без побочных эффектов. `window.Rules`.
- **save** — обёртка над localStorage. `window.Save`.
- **ui** — рендер и DOM. Не знает про состояние и правила. `window.UI`.
- **game** — состояние, view-модель, диспетчеры. `window.Game`.

Каждый модуль регистрирует методы через `Object.assign(window.X, {...})`,
поэтому порядок подключения в `index.html` критичен:

    data → rules → save → ui-* (ядро → соседи → ui.js) → game-* (state → viewmodel → actions → commands → game.js)

UI не читает `state` и не знает про правила. Логика не трогает DOM.
Единственная точка встречи состояния и представления — `game-viewmodel.js`.

## Ключевые понятия

Три независимых потока данных:
- `state` — локация, инвентарь, флаги, переменные, uiTab, controlsOpen, logOpen.
- `logEntries` — «История событий»: только переходы. Лимит 10, новые сверху.
- `infoEntries` — «Информация»: результат последнего осмысленного действия.
  Лимит 6, заменяется целиком.

Элемент `infoEntries` — `{ kind: "text", text }` или `{ kind: "image", src, alt?, caption? }`.

`Rules.applyEffect` — чистый редьюсер: принимает `state`, возвращает новый `state`
и массив сообщений `{ kind: "move" | "info", text }`. `move` идёт в «Историю»,
`info` — в «Информацию».

## Контент

Всё содержимое — в `js/data/data.js`: локации, предметы, персонаж, стартовое
состояние, граф переходов (`links`).

Условия и эффекты — декларативные, описаны в `rules.js`. Полный список типов
условий и эффектов — в шапке `rules.js`.

## Соглашения

- Пути к картинкам — относительно `index.html`, не относительно файла с данными.
- Имена файлов: `<locationId>.jpg`, `<itemId>.jpg`, `<characterId>.png`,
  сцены внутри локации — `university-classroom.jpg`.
- Идентификаторы — `snake_case`.
- Стили — на CSS-переменных из `styles-base.css` (тёмная тема = переопределить `:root`).
- `styles-responsive.css` подключается последним.

## Куда что добавлять

- Новый контент — `data.js`.
- Новое правило (условие/эффект) — `rules.js`, затем использование в `data.js`.
- Новый элемент UI — новый `ui-*.js`, регистрация методов в `window.UI`,
  подключение до `ui.js`.
- Новая игровая логика — новый `game-*.js`, регистрация в `window.Game`,
  подключение до `game.js`.
